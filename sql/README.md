# SQL Scripts

This folder contains all SQL scripts used for the Ecommerce Sales Dashboard project.

The scripts are organized by topic to make them easy to understand and reuse.

## Files

| File | Description |
|------|-------------|
| 01_database_setup.sql | Database creation and setup |
| 02_basic_queries.sql | Basic SQL queries (SELECT, WHERE, ORDER BY) |
| 03_aggregate_analysis.sql | Aggregate functions, GROUP BY, HAVING |
| 04_sales_analysis.sql | Sales-related business analysis |
| 05_customer_analysis.sql | Customer analysis queries |
| 06_product_analysis.sql | Product and category analysis |
| 07_window_functions.sql | Ranking and analytical functions |
| 08_cte_queries.sql | Common Table Expressions (CTEs) |
